# Temporary work and previews

[Project overview](../README.md) · [Presentation guide](../presentations/README.md)

This folder holds local communication drafts and previews. Current work is in
`portfolio-preview/`: website/storyboard HTML, inspection scripts, animation
rendering scripts and generated preview media.

Generated images, videos, frame directories and captured served-page copies are
ignored. Authored HTML/CSS, Python/JavaScript source and notes remain visible to
Git. Existing tracked preview artifacts remain tracked.

Research implementations belong in `robot_adaptation/`; executable experimental
choices belong in `experiments/`; new scientific outputs belong in `runs/`.
Summarize a result on its study page before using it in presentation or website
copy. Preview copies here are not evidence that a website was published.
