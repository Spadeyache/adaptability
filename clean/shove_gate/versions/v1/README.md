# Archived first pilot

100 shoves on the same ten pilot cubes. The contact API omitted tangential impulses in oblique pushes, so its claimed full-force bound was invalid. Horizontal force reconstructed from pusher momentum was below every cap, but the locked Z axis prevented a full 3D reconstruction. These motion files are retained as diagnostics and excluded from the active dataset. Active v2 frees pusher translation in all three axes and verifies actual 3D force by momentum balance. Cube identities, properties and randomized plans are unchanged.
