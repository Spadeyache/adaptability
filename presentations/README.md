## Saving new work

Keep editable scripts, content, construction plans and provenance in Git.
Generated raw API snapshots, validation reports, previews, plots and deck exports
are ignored for new files. Already tracked historical artifacts remain tracked.
Place curated source media that must be versioned in an `assets/` directory.

Keep new output in a clearly named authoring folder, and identify the current
work here instead of renaming historical directories or breaking their links.
